# Node.js Server Assignment

## Step 1: Node.js Installation

Node.js and npm were installed successfully. Their versions were checked using the following commands:

```bash
node -v
npm -v
```

## Step 2: Project Folder Creation

The project folder `node-server-demo` was created using the following commands:

```bash
mkdir node-server-demo
cd node-server-demo
```

## Step 3: Project Initialization

The Node.js project was initialized using:

```bash
npm init -y
```

This command created the `package.json` file.

![Screenshot #3](screenshots/screenshot%233.png)

## Step 4: Server File Creation

A `server.js` file was created containing the Node.js HTTP server code. The server is configured to run on port `3000` and display **Hello Javascript**.

### Screenshot #4

![Screenshot #4](screenshots/screenshot%234.png)

---

## Step 5: Start the Server

The server was started using:

```bash
node server.js
```

The server started successfully on port `3000`.

## Step 6: Browser Testing

The server was tested by opening the following URL in a web browser:

```text
http://localhost:3000
```

The browser successfully displayed **Hello Javascript**.
